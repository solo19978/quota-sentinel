# Contributing

The project is currently in experimental Windows development; version 1.26.8 source is present in the repository. Source contributions and redistribution are subject to upstream licensing review. Discuss changes in an issue before substantial work.

Use synthetic fixtures for provider responses; never commit credentials, real account identifiers, private logs, transcripts, personal paths or installers. Keep integrations read-only, minimise permissions and data access, and document new network destinations and dependencies. Add tests for changed behaviour, including error paths. Report security concerns privately as described in SECURITY.md.
